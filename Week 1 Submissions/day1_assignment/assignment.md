## Submission File

```text
day1_assignment.py
```

## Tasks

1. Write a function `is_prime(number)` that returns `True` if the number is prime.
2. Write a function `reverse_string(text)` without using slicing.
3. Write a function `calculate_cart_total(items)` where `items` is a list of prices.
4. Write a function `find_largest(numbers)` without using `max()`.
5. Write a function `generate_multiplication_table(number)` that returns a list of 10 values.

## Evaluation

- Correct function output.
- Proper use of loops and conditions.
- Clean function names.
- No hard-coded answers.
