# Day 5 Assignment: Database Fundamentals and SQL

## Submission File

```text
day5_database_sql_answers.sql
```

## Objective

Test database fundamentals, SQL joins, filtering, grouping, and aggregation.

## Required Setup

Use the database scripts from:

```text
week1_training/database/sql/
```

You may use either MySQL or PostgreSQL.

## Tasks

1. Create the database schema.
2. Insert the provided seed data.
3. Write a query to fetch all customers.
4. Write a query to fetch all active products.
5. Write a query to fetch all orders with customer names.
6. Write a query to fetch order items with product names.
7. Write a query to calculate total amount for each order.
8. Write a query to calculate revenue per customer.
9. Write a query to find the top 3 products by quantity sold.
10. Write a query to find customers who have not placed any order.

## Python Connectivity Task

Run one of the Python examples:

```text
week1_training/database/python/mysql_example.py
week1_training/database/python/postgres_example.py
```

Submit copied output or a screenshot showing the script ran successfully.
